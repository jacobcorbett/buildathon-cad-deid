# CAD De-ID

Buildathon entry for the Machina engineering corpus de-identification challenge.

[Official track brief and submission page](https://www.joinbuilders.org/buildathon/tracks/machina-deid)

The submission cutoff is Sunday 22 November 2026 at 11 am ET (4 pm UK time).

## Local setup

The official challenge PDF and upload helper are in `.buildathon/` on Yoga. The track page has the current rules, including the private hosted submission option. The corpus is roughly 140 GB before extraction or generated output.

Store raw input, outputs and identity mappings privately outside Git. The public repository is for pipeline code and documentation. An official submission consists of the de-identified corpus, source code and reproducible run instructions. The scorer checks both identity replacement and engineering usability.
